## Easily embed commands into your message.

This uses discords: **</command-name:command-id>** but makes it quicker to do!
All you have to do is cick the command you want. Right click the bar just above the message box, then just press Copy Command Format! It's that easy.

![Preview 1](https://i.imgur.com/kfSmXg3.png)

![Preview 2](https://i.imgur.com/Hn7in1k.png)

## Please read!!

If you are trying to copy a command that has multiple choices / options. Make sure when you coppied the format you didnt copy the option. To test this just quickly paste it with CTRL + V and make sure the name ( </command-name:...> ) matches with the actual command. e.g: **/leveling** -> </**leveling**:123456789> and NOT **/leveling** -> </**give**:123456789>
